# Доставка идей на почту

`POST /api/ideas` отправляет заявку через Resend и больше не записывает её
в таблицу `ideas`. Старые заявки остаются доступны в админ-панели.

Перед публикацией настройте серверные переменные окружения в Sites:

- `RESEND_API_KEY` — секретный API-ключ Resend с разрешением на отправку писем.
- `IDEAS_EMAIL_TO` — почта получателя заявок.
- `IDEAS_EMAIL_FROM` — адрес отправителя на подтверждённом в Resend домене.

Для локальной разработки используйте игнорируемый `.env.local`.
Не добавляйте ключ в Git, клиентский код или `.openai/hosting.json`.

В письме передаются имя, email и полный текст идеи. `Reply-To` указывает на
автора заявки; адрес получателя задаётся только на сервере.

Форма показывает успех только после подтверждения приёма письма сервисом.
При ошибке отправки текст формы сохраняется, пользователь может повторить
попытку. Приём сервисом не гарантирует доставку во входящие: проверяйте
статус доставки в Resend. При сетевом сбое после приёма письма повторная
попытка может создать дубликат.

Не публикуйте переключение без настроенных переменных и проверки доставки
на указанный адрес. Проверки с подменённым почтовым API:
`node --test tests/idea-email.test.mjs`.

API: https://resend.com/docs/api-reference/emails/send-email
